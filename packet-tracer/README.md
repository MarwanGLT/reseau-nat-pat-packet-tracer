# Maquettes Cisco Packet Tracer

À ouvrir avec Cisco Packet Tracer (version 8 ou plus récente).

| Fichier | Contenu |
| --- | --- |
| `tp-nat-001/TP-NAT-001-etapes-1-2.pkt` | Interfaces configurées et routage statique entre le réseau des postes et le réseau des serveurs |
| `tp-nat-001/TP-NAT-001-etape-3.pkt` | Ajout d'un routeur et d'un serveur pour simuler le WAN |
| `verysmart/VerySmart-etape-1.pkt` | Maquette VerySmart, exercice d'évaluation d'octobre : étape 1 |
| `verysmart/VerySmart-etape-2.pkt` | Maquette VerySmart : étape 2 |
